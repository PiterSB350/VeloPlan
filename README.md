# VeloPlan – edytor treningów (UC9)

Aplikacja HTML5/CSS3/JavaScript z laboratorium z Inżynierii Programowania. Realizuje przypadek użycia UC9 „Tworzenie własnych treningów” (FR7) fikcyjnego systemu VeloPlan do treningu na trenażerze rowerowym.

## Funkcje
- nazwa treningu i lista interwałów (czas, % FTP, opcjonalnie kadencja),
- profil treningu rysowany na bieżąco, łączny czas i moc w watach (wg FTP),
- walidacja z oznaczeniem błędnego pola, blokada zapisu,
- biblioteka zapisanych treningów (localStorage przeglądarki).

## Uruchomienie
Otwórz `index.html` w przeglądarce (bez serwera i instalacji).

## Struktura
`index.html`, `style.css`, `app.js`
